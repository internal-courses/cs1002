Severe / Moderate Thrashing

Over-attempting without learning. More attempts won't help — they need forced reflection.
What to do Severe: live 1-on-1 within 24h — ask student to explain code line-by-line, run 3 tiny custom cases.
Moderate: mandate a "write before you run" rule — no new attempt without writing expected output first.
Who owns it TA live support (severe) / TA clinic (moderate)
⏱ Severe: 24h · Mod: 48h
